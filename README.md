# 星铁模拟器（崩坏：星穹铁道 伤害及配队模拟器）

一个纯本地运行的回合制战斗模拟器，模拟《崩坏：星穹铁道》任意队伍的伤害与配队表现。

> ⚠️ **免责声明**：本项目为非官方、非盈利的同人学习工具，与米哈游（miHoYo/HoYoverse）无任何关联。游戏名称、角色、技能等内容的著作权与商标权归米哈游所有。本项目仅用于数值模拟与学习交流，不包含任何游戏资源文件，不用于商业用途。

## 功能特性

- **回合制战斗引擎**：第四象限行动条模型（Y 轴常规行动 + X 轴额外回合/终结技），含行动值(AV)、击破、境界、忆灵召唤、欢愉/记忆双命途子系统
- **完整角色库**：40 名完整录入角色 + 52 空壳桩，覆盖直伤/DOT/击破/超击破/欢愉 5 大伤害体系（含知更鸟·晴歌三忆灵、姬子·启行拓星视界等机制）
- **配队推荐**：遗器副词条智能推荐——总词条 50 固定、有效词条可调（默认 30）、九属性词条（含效果命中）、逐角色信号个体化权重、单词条占比推荐上限、套装条件约束（龙骨/贝洛伯格等）、毕业度评分
- **遗器/光锥**：60 套遗器 + 144 光锥数据

## 快速开始

**环境要求**：Python 3.10+

```bash
# Windows：双击 启动.bat（自动安装依赖并启动）

# 或手动：
cd 模拟器本体
pip install -r requirements.txt
python main.py
```

启动后浏览器打开 http://127.0.0.1:8000 即可使用。

## 目录结构

```
模拟器本体/
  engine/          # 战斗引擎（核心计算）
    models/        # 角色/敌人/遗器/光锥数据模型
    core/          # 回合制引擎 + 遗器副词条推荐
    systems/       # 欢愉/记忆命途子系统
  web/             # FastAPI 后端 + 前端 SPA
  data/            # 角色/光锥/遗器/敌人 JSON 数据
  tests/           # pytest 测试（1238 用例）
  角色技能介绍/     # 角色技能 TXT 原文（录入数据源）
```

## 运行测试

```bash
cd 模拟器本体
python -m pytest tests/ -q
```
