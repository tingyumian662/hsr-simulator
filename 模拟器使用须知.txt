模拟器的运行需要电脑上下载有3.10+版本的python运行环境，下载时记得勾选Add to PATH
双击文件夹中的启动.bat文件即可开启模拟器，如果没有python环境会提示，首次开启会自动下载pip依赖，后续就不再需要了。
该版本的模拟器中没有录入数据的角色后面会括号显示空壳，可选但无法计算。

常见问题与注意事项（强烈建议先看完）
════════════════════════════════════════

【首次使用三步】
1. 安装 Python 3.10+（https://www.python.org/downloads/），安装时务必勾选 "Add Python to PATH"
2. 装完 Python 后【重启一次电脑】（重要！不重启的话系统还认不出刚装的 Python）
3. 解压整个模拟器文件夹，双击 启动.bat

【首次运行】
- 需要联网（自动下载约 15MB 的依赖包，仅第一次），之后可离线使用
- 浏览器会自动打开 http://127.0.0.1:8000
- 如果浏览器打开后显示"无法连接"，先按 F5 刷新一下（可能是服务启动稍慢）

【报错排查对照表】
- 双击后提示 "Python not found" → 没装 Python，或装完没重启
- 提示依赖安装失败 → 网络不通，检查网络后重新双击
- 浏览器能打开但显示"拒绝连接" → 看黑窗口：
    · 黑窗口有 "Uvicorn running" → 刷新浏览器即可
    · 黑窗口显示 "address already in use" → 8000 端口被占用，把 启动.bat 里的 8000 改成 8001 再试
    · 黑窗口有红字 Traceback → 把红字内容截图发给提供者

【其他注意】
- 整个 ：/星铁模拟器 文件夹要一起拷贝/压缩（data 文件夹是角色数据，缺失会导致角色加载失败）
- 建议用压缩包(zip)方式传文件，不要单独传个别文件
- 端口默认 8000，如被其他软件占用可自行修改 启动.bat 中的端口号
